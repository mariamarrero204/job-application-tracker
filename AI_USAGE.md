# AI Usage Documentation

## Tools Used
- ChatGPT for HTML/CSS design and frontend layout.
- ChatGPT for debugging, troubleshooting, and improving code organization.
- ChatGPT for generating sample companies, jobs, applications, and contacts.
- ChatGPT for the initial application scaffold and development guidance.

## Key Prompts
1. "Create a clean and organized HTML/CSS interface for a Job Application Tracker."
2. "Help me debug errors while connecting Flask to MySQL."
3. "How can I test CRUD operations and verify database records?"
4. "Suggest ways to improve code readability and organization."
5. "Generate realistic sample data for testing the Job Application Tracker."

## What Worked Well
- AI helped create a consistent and functional frontend design.
- Useful for identifying errors and explaining possible solutions.
- Helped organize the development and testing process.
- Generated realistic sample records for testing different application features.
- Made troubleshooting easier when working with Flask, Python, and MySQL.

## What I Modified
- Configured the Python environment and MySQL database connection.
- Set up and tested the application using IntelliJ IDEA and MySQL Workbench.
- Reviewed the Flask routes, database functions, and SQL queries.
- Tested CRUD operations and verified database records using SQL.
- Added and verified sample companies, jobs, applications, and contacts.
- Checked database relationships, application statuses, and dashboard functionality.

## Lessons Learned
- AI is useful for frontend design, debugging, and organizing code.
- Testing code manually is important, even when AI provides working examples.
- SQL queries help verify that database operations are functioning correctly.
- Breaking development into smaller tasks makes troubleshooting easier.
- Understanding and testing the code is more important than simply getting it to run.
